## Worum es geht

Der Editor arbeitet, ohne etwas über Sie an seinen Hersteller zu senden. Nur wenn Sie einwilligen,
sendet er die unten genannten Zahlen, damit der Hersteller sieht, ob und wie viel der Editor benutzt
wird. Sie werden einmal gefragt, zu beiden Teilen getrennt, und nichts ist vorab angekreuzt. Ein Nein ändert nichts daran, was der Editor kann.

## 1. Lebenszeichen beim Start (nur mit Ihrer Einwilligung)

Einmal bei jedem Start des Editors:

- eine Zufallszahl, die auf Ihrem Computer erzeugt wurde, als Sie eingewilligt haben (die Nummer
  der Installation). Sie ist nicht aus Ihrem Namen, Ihrem Computer oder sonst etwas über Sie abgeleitet;
- die Version des Editors;
- die Art des Systems (zum Beispiel „macos aarch64“).

## 2. Zahlen einer Sitzung (nur mit Ihrer gesonderten Einwilligung)

Einmal beim Schließen des Editors; schlägt das fehl, beim nächsten Start:

- Nummer der Installation, Version und Art des Systems wie oben;
- wie lange der Editor geöffnet war, in Minuten;
- wie viele Anfragen an eine KI gingen, nach Art des Anbieters und Name des Modells;
- an wie vielen Dokumenten gearbeitet wurde;
- wie viele Wörter hinzugekommen sind.

## Was nie gesendet wird

Ihr Text, Ihre Fragen, die Antworten der KI, Dateinamen, Pfade, die Adresse Ihres Anbieters,
API-Schlüssel, Ihr Benutzername, der Name Ihres Computers. Auch das technische Protokoll des Editors
(diagnostics.log) wird nicht gesendet; es verlässt Ihren Computer nur, wenn Sie es selbst einem Fehlerbericht hinzufügen.

Chats und Dateien aus anderen KI-Werkzeugen, die Sie zu einer Angabe über die Nutzung außerhalb
ablegen, werden ebenfalls nirgendwohin gesendet, und die KI, die Sie im Editor fragen, bekommt sie
nicht. Sie liegen im `.cowriting`-Ordner des Dokuments auf Ihrem Computer. Wer diesen Ordner von
Ihnen bekommt, in einem geteilten oder synchronisierten Ordner oder mit einer Abgabe, bekommt
auch sie: Legen Sie nur die Unterhaltungen ab, die zur Arbeit gehören, und achten Sie darauf,
was darin über andere Personen steht.

Kommt eine Meldung an, sieht der Server die Internetadresse, von der sie kam, wie jeder Server.

## Die Prüfung auf eine neuere Version

Unabhängig von den Zahlen oben und ohne die Nummer der Installation: Eine veröffentlichte Version
des Editors fragt bei jedem Start den Server des Herstellers, ob es eine neuere Version gibt,
solange Sie das in den Einstellungen unter „Über“ nicht abgeschaltet haben. Die Anfrage nennt
nichts: keine Version, keine Nummer, nichts über Ihr System oder Ihre Dokumente. Wie bei jeder
Anfrage sieht der Server die Internetadresse, von der sie kommt. Wenn Sie selbst ein Update
starten, wird die neue Version von den Releases des Projekts auf GitHub geholt (GitHub, Inc.,
USA); dann sieht auch GitHub Ihre Internetadresse.

## Rechtsgrundlage, Speicherung, Empfänger

Rechtsgrundlage ist Ihre Einwilligung (Art. 6 Abs. 1 lit. a DSGVO; für das Auslesen der Nummer der Installation von Ihrem Computer § 25 Abs. 1 TDDDG).
Die Zahlen werden bei [[Hosting-Anbieter und Land]] für [[Speicherdauer]] gespeichert und an niemanden sonst weitergegeben.

## Ihre Rechte

Sie können jede der beiden Einwilligungen jederzeit in den Einstellungen unter „Über“ widerrufen; von da an
wird nichts mehr gesendet, und sind beide widerrufen, wird die Nummer der Installation von Ihrem Computer gelöscht.
Die Einstellungen zeigen genau, was gesendet würde. Sie haben das Recht auf Auskunft, Berichtigung, Löschung,
Einschränkung, Datenübertragbarkeit und auf Beschwerde bei einer Datenschutzaufsichtsbehörde. Um bereits
gesendete Zahlen löschen zu lassen, nennen Sie die Nummer der Installation (die Einstellungen zeigen sie, solange eine Einwilligung besteht).
